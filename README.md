
# TiK

Une application simple, concentrée sur les fonctionnalités essentielles pour une gestion des tickets de bug


 La base de données cesse d'exister dès que la connexion à la base de données est fermée. Chaque base de données :memory: est distincte des autres. Ainsi, ouvrir deux connexions à une base de données avec le nom de fichier ":memory:" créera deux bases de données indépendantes en mémoire.
